# SOLO Research — фронтенд

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4. Язык по умолчанию — грузинский (`ka`), без префикса в URL.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

## Где что лежит

- `src/i18n/dictionaries/ka.ts` — все тексты интерфейса. Новый язык: добавить код в `src/i18n/config.ts`, словарь и папку `src/data/i18n/<locale>` (URL будет `/en/...`).
- `src/data/` — товары, категории, COA, настройки сайта (`site.ts`: email, валюта, порог бесплатной доставки).
- `src/data/i18n/ka/` — описания товаров, категорий, FAQ, юридические тексты.
- `src/lib/api/` — единая точка доступа к данным; при подключении админки меняется только она.
- `src/proxy.ts` — `/products` → `/ka/products` (внутренний rewrite).

## Админ-панель (`/admin`)

Товары с вариациями и фото, категории, COA (PDF), FAQ, юридические тексты, все тексты страниц (3 языка), контакты/футер.

- Данные: Neon Postgres, таблица `site_content` (один JSON-документ на ключ, см. `src/lib/content`). Пока документ не сохранён из админки, берутся файлы из `src/data` и словари — это «значения по умолчанию».
- Тексты страниц хранятся как отличия от словарей (`src/i18n/overrides.ts`), поэтому правки словарей в коде доходят до неизменённых полей.
- Фото и PDF: Vercel Blob (`/api/admin/upload`, загрузка прямо из браузера).
- Вход: одна переменная `ADMIN_PASSWORD`. Сохранение сбрасывает кэш (`updateTag("content")` + `revalidatePath`), сайт остаётся статическим.
- Переменные окружения: `DATABASE_URL`, `BLOB_READ_WRITE_TOKEN`, `ADMIN_PASSWORD`.

## Перед запуском проверить

- Цены — заглушки (`src/data/products.ts`).
- CAS / формулы / молекулярные массы / последовательности — справочные, сверить с документацией поставщика.
- Лоты COA — демо (`src/data/coa.ts`); PDF класть в `public/files/coa/` и прописывать `fileUrl`.
- Юридические тексты, email, соцсети, часы работы, тарифы доставки — заглушки.
- Фото есть у 8 товаров (низкое разрешение из дизайн-макета); у остальных — SVG-флакон с названием.
- Оплата, аккаунты, отправка форм — не подключены (этап бэкенда).
